# FinAlly Project - the Finance Ally

All project documentation is in the `planning` directory.

- `planning/PLAN.md` is the specification and is included in full below.
- `planning/API_CONTRACT.md` is the single API/SSE contract for backend and frontend. Read it before touching any endpoint or price field, and change the API only by editing that file.
- The market data design is in `planning/MARKET_INTERFACE.md`, `planning/MARKET_SIMULATOR.md` and `planning/MASSIVE_API.md`.
- Build progress is tracked in `.planning/ROADMAP.md` and `.planning/STATE.md`.

Consult these docs only when required.
