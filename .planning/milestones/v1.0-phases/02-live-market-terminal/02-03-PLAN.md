## Phase Goal

**As a** FinAlly user, **I want to** open the app and watch the 10 default tickers stream live in a dark terminal, with $10,000 cash shown and a live connection indicator, **so that** I can see the market move before I trade.

(Story assembled from the ROADMAP Phase 2 `**Goal:**` line and the PROJECT core value; see the planner return.)

<objective>
Make the simulator's prices believable and reproducible: realistic seed prices and volatility, sector correlation, occasional 2-5% events, a stable ticker-derived start price for any symbol, and `SIM_SEED` reproducibility, all proven by the market-data unit tests.

Purpose: MKT-01, MKT-02, MKT-03, MKT-04 and the simulator half of MKT-06 and TEST-01. Phase 3 adds unknown tickers to the watchlist; they must start at the same price on every restart, and E2E runs with `SIM_SEED=1` must be deterministic.
Output: `derived_price()` in `simulator.py` and `backend/tests/market/test_simulator.py`.

Tracer: Task 1 is the thinnest path through every layer this plan touches: ticker -> `derived_price` -> `GBMSimulator.add_ticker` -> `SimulatorDataSource.add_ticker` -> `PriceCache`, proven in-process and in a fresh Python process. Task 2 expands it with the GBM math, correlation, event and seeding tests.
</objective>
