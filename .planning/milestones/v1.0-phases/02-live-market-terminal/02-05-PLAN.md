## Phase Goal

**As a** FinAlly user, **I want to** open the app and watch the 10 default tickers stream live in a dark terminal, with $10,000 cash shown and a live connection indicator, **so that** I can see the market move before I trade.

(Story assembled from the ROADMAP Phase 2 `**Goal:**` line and the PROJECT core value; see the planner return.)

<objective>
Put the live market on screen: replace the Phase 1 page with the terminal shell and a watchlist panel whose 10 rows (from `GET /api/watchlist`) show live prices and change % from one `EventSource`, formatted by one shared formatter module, with the UI-SPEC theme and every panel state, plus the Vitest harness for the frontend logic.

Purpose: UI-01, UI-03, UI-04 (rows), UI-08, and the browser side of WL-01. Plans 02-06 (header, connection dot, footer) and 02-07 (flash, sparklines) build on this store, hook and row.
Output: types, API client, formatters, zustand store, stream hook, `WatchlistPanel`, `WatchlistRow`, the new page, theme tokens, Vitest setup and unit tests, and the rewritten E2E smoke.

Tracer: Task 1 is the thinnest path through every layer this plan touches: browser -> `GET /api/watchlist` (membership) + `EventSource` -> zustand store -> `WatchlistRow` -> a Playwright run against the real backend and simulator. Task 2 adds the Vitest harness and the logic tests; Task 3 adds the theme and the loading, error and empty states.
</objective>
