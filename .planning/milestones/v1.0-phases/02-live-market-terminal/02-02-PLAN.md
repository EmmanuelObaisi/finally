## Phase Goal

**As a** FinAlly user, **I want to** open the app and watch the 10 default tickers stream live in a dark terminal, with $10,000 cash shown and a live connection indicator, **so that** I can see the market move before I trade.

(Story assembled from the ROADMAP Phase 2 `**Goal:**` line and the PROJECT core value; see the planner return.)

<objective>
Give the stream a real home: a SQLite database created and seeded in the lifespan before the first request, the tracked tickers loaded from it, and the two read endpoints the terminal needs, `GET /api/watchlist` and `GET /api/portfolio`.

Purpose: DB-01, DB-02, DB-03, WL-01 and PORT-01. Plans 02-05 and 02-06 render these endpoints; Phases 3-5 write trades, snapshots and chat rows into this schema. It also settles the open 404-versus-405 question (Phase 1 review WR-01) in the contract before more routes arrive.
Output: `backend/app/db.py`, `watchlist.py`, `portfolio.py`, lifespan wiring, tests, and two contract sentences.

Tracer: Task 1 is the thinnest live path through every layer this plan touches: fresh `DB_PATH` -> `init_db` seed -> `load_tracked_tickers` -> `source.start` -> `PriceCache` -> `GET /api/watchlist` answered by a real uvicorn process. Tasks 2 and 3 expand it with database guarantees and the portfolio read.
</objective>
