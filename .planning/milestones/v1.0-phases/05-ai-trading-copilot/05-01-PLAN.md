## Phase Goal

**As a** FinAlly user, **I want to** chat with FinAlly, which understands my portfolio and executes trades and watchlist changes on my behalf, **so that** I can analyze and act on my portfolio in plain language.

(Story assembled from the ROADMAP Phase 5 `**Goal:**` line; the Goal line is not written as a user story. See the planner return.)

<objective>
Build the LLM layer the chat turn runs on: the strict-schema-friendly reply models, the deterministic mock, the one `complete()` seam (mock or real LiteLLM -> OpenRouter -> Cerebras call), and the prompt builder with portfolio context and outcome-annotated history. First, gate `litellm` behind one human approval because it carries a documented supply-chain compromise history.

Purpose: CHAT-02, CHAT-03, CHAT-09 and the LLM half of TEST-03. Plan 05-02 runs a whole chat turn on top of this layer; the mock sharing the same seam as the real client means mock-mode tests exercise the same parse, execute and persist path the real model uses (D-12).
Output: `backend/app/llm/{__init__,schema,mock,client,prompt}.py`, the litellm pin in `pyproject.toml` and `uv.lock`, four test files, and the manual `live_smoke.py`.

Tracer: Task 2 is the thinnest path through every layer of this plan: `complete()` in mock mode returns raw JSON that `ChatReply` parses into the trade the keyword asked for, with the real dependency installed and proven never imported on that path. Task 3 builds the prompt and pins the schema and the real-branch call shape.
</objective>
