## Phase Goal

**As a** FinAlly user, **I want to** see the selected ticker's price chart, a P&L heatmap of my positions and my portfolio value over time, **so that** I can read my portfolio and the market at a glance.

(Story assembled from the ROADMAP Phase 4 `**Goal:**` line; the Goal line is not written as a user story. See the planner return.)

<objective>
Chart the portfolio's value over time. The P&L panel reads `GET /api/portfolio/history` (plan 04-01), appends a live "now" point equal to the header total, refetches every 30 s and after every portfolio change, and shows an explicit empty state only while the user has never traded (UI-SPEC Decision 8, confirmed by the user).

Purpose: PUI-04, the browser half of PORT-07, and the P&L part of PUI-07. Plan 04-04 adds the heatmap beside this panel.
Output: `HistoryPoint`, `getPortfolioHistory`, `historyStore`, `buildPnlSeries`, `STARTING_CASH`, `PnlChartPanel`, the workspace mid row, unit tests and the P&L E2E.

Tracer: Task 1 is the thinnest live path through every layer this plan touches: trade bar buy -> backend trade snapshot -> portfolio identity change -> `historyStore.load` -> `GET /api/portfolio/history` -> `buildPnlSeries` -> Lightweight Charts area series, proven by host Playwright. Task 2 pins the data rules; Task 3 adds the states, refetch cadence and the title-bar delta.
</objective>
