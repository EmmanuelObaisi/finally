## Phase Goal

**As a** FinAlly user, **I want to** see the selected ticker's price chart, a P&L heatmap of my positions and my portfolio value over time, **so that** I can read my portfolio and the market at a glance.

(Story assembled from the ROADMAP Phase 4 `**Goal:**` line; the Goal line is not written as a user story. See the planner return.)

<objective>
Show the portfolio as a P&L heatmap: one tile per position, area by live market value, tint by P&L %, beside the portfolio value chart. Then prove all four PUI-07 empty states (watchlist, positions, heatmap, P&L chart) together in a real browser.

Purpose: PUI-03 and the closing proof of PUI-07. Completes the Phase 4 workspace.
Output: the two approved d3 pins, `heatmap.ts`, `useElementSize`, `HeatmapTile`, `HeatmapPanel`, the ResizeObserver test stand-in, a Retry that shows the loading state, unit tests and the heatmap and empty-state E2E.

Tracer: Task 1 is the thinnest live path through every layer this plan touches: approved install -> trade bar buys -> portfolio store -> `buildTiles` (d3-hierarchy squarify) -> measured tiles box -> absolutely positioned tiles, proven by host Playwright with a weight-to-area check. Task 2 pins tile geometry, colors and labels; Task 3 adds the states, Retry and the combined empty-state proof.
</objective>
