## Phase Goal

**As a** developer, **I want to** build and run an end-to-end skeleton of FinAlly on this machine (local and in Docker) against one frozen API/SSE contract, **so that** every later phase adds one visible capability to an app that already runs.

(Story assembled from the ROADMAP Phase 1 `**Goal:**` line and the ROADMAP Overview; see the planner return.)

<objective>
Stand up the backend as a uv virtual project in `backend/`: a FastAPI app factory under `backend/app/` answering `GET /api/health`, reading every setting from env plus the project-root `.env`, returning the `{"error": ...}` envelope for every failure, and mounting the static export last. The test suite runs with `uv run python -m pytest`.

Purpose: FND-02, FND-05 and PORT-08. Every later route plugs into this factory, error envelope and Settings object (01-PATTERNS.md shared patterns: settings via `request.app.state.settings`, routers added above the `/api` catch-all).

Tracer: Task 2 is the thinnest live path through this slice: uv project -> `create_app()` -> `/api/health` -> a real uvicorn process answering curl. Task 3 expands it with the error envelope and the config tests.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser -> FastAPI | Untrusted HTTP requests reach routes and the static mount |
| environment / .env -> Settings | Secrets (API keys) enter process memory |
| PyPI -> backend/.venv | Third-party code enters the build |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
