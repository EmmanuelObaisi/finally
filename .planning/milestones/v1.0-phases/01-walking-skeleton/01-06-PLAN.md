## Phase Goal

**As a** developer, **I want to** build and run an end-to-end skeleton of FinAlly on this machine (local and in Docker) against one frozen API/SSE contract, **so that** every later phase adds one visible capability to an app that already runs.

(Story assembled from the ROADMAP Phase 1 `**Goal:**` line and the ROADMAP Overview, as in plans 01-01 to 01-05.)

<objective>
Close the verification blocker CR-01 and the backend review warnings WR-03 and WR-05 (gap closure for 01-VERIFICATION.md).

- CR-01: `Settings.from_env()` crashes on `SIM_EVENT_PROBABILITY=` (empty), which is exactly what the committed `.env.example` and Docker `--env-file` produce. Every config variable must treat an empty value as unset and fall back to its default (FND-05, ROADMAP SC2).

Purpose: SC2 says running the app locally picks up the project-root `.env`. With the project's own template that currently crashes. After this plan the template boots, the tests prove it without touching the developer's environment, and the error contract holds for every method.
Output: `backend/app/config.py` (env helper), `backend/app/main.py` (all-method catch-all), `backend/tests/conftest.py` (new), updated `test_config.py`, `test_errors.py`, `test_health.py`, and three disposition rows marked fixed.
