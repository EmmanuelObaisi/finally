## Phase Goal

**As a** FinAlly user, **I want to** launch FinAlly with one command, **so that** I get the live trading terminal on http://localhost:8000 and every PLAN.md §12 unit and E2E scenario is proven against the running container.

(Story assembled from the ROADMAP Phase 6 `**Goal:**` line, which is not written as a user story; see the planner return.)

<objective>
Make the Playwright suite run from the host against a throwaway container with one command, `npm --prefix test run e2e`, and make that run honest: fresh database every run, mock env proven inside the container, no silently skipped tests, guaranteed teardown.

Purpose: TEST-06 infrastructure and D-01 to D-03 (D-05's container handle). Today the container run silently skips the P&L chart and heatmap tests; after this plan the official run executes all 17 existing tests and fails on any skip.
Output: `test/e2e.mjs`, the `e2e` npm script, the lifted skips in `test/portfolio-charts.spec.ts`.

Tracer: Task 1 wires the whole path once (npm script, wrapper, compose up of the test project, mock-pin proof, Playwright on the host against port 8001, JSON summary, teardown) and runs the existing suite through it green with zero skips. Task 2 proves the failure paths on that wrapper: an aborted startup and a dirty leftover project.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| wrapper -> Docker daemon | The wrapper creates and removes containers and volumes on the user's machine |
| test container -> network | A container started without the mock pins would call OpenRouter or Massive with the user's keys |
| wrapper -> terminal and logs | Output is read by humans and agents; secrets must not appear |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-06-05 | Tampering | `down -v` in `test/e2e.mjs` | high | mitigate | Every compose call passes `-p finally-test` explicitly (plus the env var); Task 1 verify compares the user's volumes and `finally:*` image ids before and after and asserts no finally-test leftovers |
| T-06-06 | Tampering (cost) | Real LLM or Massive calls from the test container | high | mitigate | Literal pins in `test/compose.e2e.yml`; the wrapper checks `LLM_MOCK=true` and an empty `MASSIVE_API_KEY` inside the running container and aborts before Playwright if either fails |
| T-06-07 | Information disclosure | Wrapper output | medium | mitigate | The wrapper prints only fixed status lines, the Playwright list output and the summary; it never prints the environment or `docker compose config`; acceptance greps for env or config dumps |
| T-06-SC | Tampering | npm/pip/cargo installs | low | accept | No packages are installed; the wrapper uses Node built-ins and the already pinned @playwright/test 1.63.0 |
</threat_model>
