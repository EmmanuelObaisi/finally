## Phase Goal

**As a** FinAlly user, **I want to** open the app and watch the 10 default tickers stream live in a dark terminal, with $10,000 cash shown and a live connection indicator, **so that** I can see the market move before I trade.

(Story assembled from the ROADMAP Phase 2 `**Goal:**` line and the PROJECT core value; see the planner return.)

<objective>
Make the watchlist feel alive and prove the whole phase where users run it: green and red price flashes that fade over 500 ms, a sparkline per row that fills in from page load, dimmed rows while the stream is down, and then the rebuilt Docker image serving the complete terminal, stopping promptly with a browser connected, with the README updated.

Purpose: UI-05, the sparkline half of UI-04, the row side of UI-08, and the container-level proof of MKT-10 and UI-01 (ROADMAP success criteria 1, 2 and 5).
Output: `PriceCell`, `Sparkline`, `chartTheme.ts`, flash and sparkline state in the store, tests, `test/motion.spec.ts`, a container proof, README and research-doc corrections.

Tracer: Task 1 is the thinnest path through every layer this plan touches: SSE frame with a newer timestamp -> `applyFrame` flash sequence -> keyed `PriceCell` -> CSS animation observed in a real browser. Task 2 adds sparklines and dimming; Task 3 proves the phase in the container.
</objective>
