## Phase Goal

**As a** FinAlly user, **I want to** open the app and watch the 10 default tickers stream live in a dark terminal, with $10,000 cash shown and a live connection indicator, **so that** I can see the market move before I trade.

(Story assembled from the ROADMAP Phase 2 `**Goal:**` line and the PROJECT core value; see the planner return.)

<objective>
Complete the terminal's chrome: a header that shows the live total value and cash from `GET /api/portfolio`, an honest connection indicator driven by a real state machine (green, yellow, red after 5 s, reconnect with backoff), refetches on reconnect, dimming of stale numbers, and the footer attribution that the sparkline library's licence requires.

Purpose: UI-02, the reconnect half of UI-03, the header side of UI-08 and PORT-01 in the browser. ROADMAP success criterion 3 (fresh database shows $10,000.00; dot green, yellow, red; page reconnects on its own).
Output: `Header`, `ConnectionDot`, `Footer`, `liveTotals`, the state machine in `useMarketStream`, unit tests and `test/connection.spec.ts`.

Task 2 adds the state machine and refetches; Task 3 adds the footer and the remaining header states.
</objective>
