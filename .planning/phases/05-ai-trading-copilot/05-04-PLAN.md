## Phase Goal

**As a** FinAlly user, **I want to** chat with FinAlly, which understands my portfolio and executes trades and watchlist changes on my behalf, **so that** I can analyze and act on my portfolio in plain language.

(Story assembled from the ROADMAP Phase 5 `**Goal:**` line; the Goal line is not written as a user story. See the planner return.)

<objective>
Put the chat in front of the user. Build the chat panel (title bar, role=log transcript with message rows and inline action lines, composer that sends on Enter, loading row, auto-scroll), the Header Chat toggle and the page placement (third grid column at 1536px and wider, right-edge overlay drawer below). Replies already refresh the portfolio views and the watchlist through the plan 05-03 stores.

Purpose: PUI-05 (panel, Enter to send, loading indicator, auto-scroll) and PUI-06 (inline action lines). Plan 05-05 adds the history loading, error and empty blocks, the composer limits, the slow-reply text, request-failure rows and the focus rules.
Output: `ChatPanel`, `ChatMessageRow`, `ChatActionLine`, `ChatToggle`, the Header and page changes, the `matchMedia` test stub, and their tests.

Tracer: Task 1 is the thinnest live path through the panel layers: composer Enter -> `useChatStore.send` -> stubbed `POST /api/chat` -> user bubble, loading row, assistant bubble with action lines -> scrolled transcript and updated portfolio store. Task 2 mounts it: Header toggle, page placement, regression build and the existing browser smoke.
</objective>
