## Phase Goal

**As a** developer, **I want to** build and run an end-to-end skeleton of FinAlly on this machine (local and in Docker) against one frozen API/SSE contract, **so that** every later phase adds one visible capability to an app that already runs.

(Story assembled from the ROADMAP Phase 1 `**Goal:**` line and the ROADMAP Overview; see the planner return.)

<objective>
Create the frontend as a hand-written Next.js 16.4 TypeScript project in `frontend/` that builds to a static export (`output: 'export'`). The export is a Tailwind-styled dark placeholder page that calls the same-origin `GET /api/health` and shows the result.

Purpose: FND-03. This page is the browser end of the walking skeleton; 01-05 serves it from FastAPI and Docker and drives it with Playwright. The conventions set here carry forward to later phases: `src/app/`, `src/lib/`, `data-testid` hooks, same-origin fetches, `@theme` tokens, and no `next/font/google` (01-PATTERNS.md "Frontend skeleton").
Output: `frontend/` package, configs, `src/app/{layout,page}.tsx`, `src/app/globals.css`, `src/lib/api.ts`.

Tracer: Task 2 is the thinnest path through this slice: manifest -> Next config -> page -> typed fetch -> static export containing that fetch. Task 3 expands it with the dark Tailwind theme.
</objective>
