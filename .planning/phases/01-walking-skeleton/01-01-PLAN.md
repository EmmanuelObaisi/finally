## Phase Goal

**As a** developer, **I want to** build and run an end-to-end skeleton of FinAlly on this machine (local and in Docker) against one frozen API/SSE contract, **so that** every later phase adds one visible capability to an app that already runs.

(Story assembled from the ROADMAP Phase 1 `**Goal:**` line and the ROADMAP Overview sentence "Each phase leaves the app runnable and adds one capability a user can see." The Goal line itself is not in canonical user-story form; see the planner return.)

<objective>
Make the repository clean before any build output exists: untrack the committed build artifacts (`backend/static/`, `test/node_modules/`, `test/playwright-report/`, `test/test-results/`), fix the `.gitignore` packaging block that would hide `frontend/src/lib/`, force LF line endings for scripts, Dockerfile and env files, delete the stale local export, and add `.env.example` and `db/.gitkeep`.

Purpose: Wave 2 installs dependencies and builds the frontend. Without these rules `node_modules/`, `.next/` and `out/` would be staged, `frontend/src/lib/` would be silently ignored, and the local backend would serve the stale old export (FND-01).
Output: `.gitignore` (edited), `.gitattributes`, `.env.example`, `db/.gitkeep`, four artifact trees removed from the index.

Tracer note: this plan has no runtime layers. Its leading `tracer` task is the thinnest end-to-end proof for this slice: the ignore and attribute rules plus the untracking, proven together by git itself.
</objective>
